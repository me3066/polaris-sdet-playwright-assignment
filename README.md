# Polaris SDET Playwright Assignment (Ready-to-run)

## Requirements
- Node.js 18+
- npm

## Install
```bash
npm install
npx playwright install
```

## Run tests
```bash
npx playwright test
```

## Notes
- Uses `data-test` as Playwright test id attribute.
- Page Object Model for maintainability.
- Includes positive and negative scenarios.
